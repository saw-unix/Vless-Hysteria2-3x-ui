# Vless-Hysteria2-3x-ui
Автор не призывает к обходу блокировок и/или нарушению существующего законодательства вашей страны. Весь материал предоставлен исключительно в ознакомительных целях и не является инструкцией по обходу блокировок. Пользуйтесь данной информацией на свой страх и риск.

Гайд подойдет для новичков, которые хотят сделать собственный **VPN** на своем сервере.

### Данный гайд предполагает наличие на вашем сервере установленного 3x-ui.
  [Установить 3x-ui](https://github.com/MHSanaei/3x-ui)

### В данном гайде будет показана настройка протоколов Vless через транспорты RAW(TCP) и XHTTP, а также Hysteria2. (3x-ui будет представлен в английском интерфейсе ради удобства).

# Настройка Vless RAW.

**Inbounds** >> **Add inbound**
1. **Basics**: можем поменять порт на 443, но это необязательно. Vless спокойно работает и на случайном порту.
2. **Stream**: транспорт оставляем по умолчанию, *RAW*.
3. **Security**: в самом начале выбираем *Reality*, uTLS ставим *Firefox*[^1], Target оставляем любой.

   **[Create]**

# Настройка Vless XHTTP.

**Inbounds** >> **Add inbound**
1. **Basics**: можем поменять порт на 443, но это необязательно. Vless спокойно работает и на случайном порту. Если вы поставили порт 443 на первом Vless соединении, то второй раз его задать не получится.
2. **Stream**: транспорт выбираем *XHTTP*.
3. **Security**: в самом начале выбираем *Reality*, uTLS ставим *Edge*[^2], Target ставим отличный от прошлого.
   **Create**
# Настройка Hysteria2.

### Для создания подключения через hysteria2 у вас должен быть домен, привязанный к IP-адресу вашего сервера.

**Inbounds** >> **Add inbound**
1. **Basics**: protocol выбираем hysteria. **Порт обязательно должен быть 443**, возможно у вас будет работать другой порт, если ваше подключение не работает -- вероятно дело в порте, подбирайте рабочий самостоятельно.
2. **Stream**: включаем *Masquerade*.
3. **Security**: в SNI указывается ваш домен. uLTS выбираем *Firefox*, ALPN оставляем только *h3*
[^1]: ТСПУ начал распознавать поддельные фингерпринты Chrome, поэтому предпочтительным является любой другой браузер, многие рекомендуют именно Firefox.
[^2]: Edge ставится как отличный браузер от первоначального, если отвалится первое подключение из-за фингерпринта, будет работать второе, по такому же принципу мы меняем target.
